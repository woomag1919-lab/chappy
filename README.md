# CoreLingual v62

アーリーアクセス向けの守り強化。

## v62 の変更
1. **招待 PATCH の先着1人ロック**（`partner_hash IS NULL` のときだけ新規回答者を受け付け）
   - 同一 `partnerKey` の再送は更新可能
   - 別人が既に回答済み → 403
   - ほぼ同時の競合 → 409
2. **ownerToken 検証を 40–60 文字に統一**
3. **会話入力の長文ヒント**（6000字超で表示、12000字超で送信前に確認）

## デプロイ
- `api/invite.js` と `index.html` を含むこの一式を Vercel に
- DBスキーマ変更なし（既存 v34 のまま）
- 環境変数: `DATABASE_URL`, `GEMINI_API_KEY`

## 確認手順
1. ホストが招待リンク作成
2. 相手が36問 → 送信 → 共有
3. 別ブラウザで同じ招待リンクを開いて回答しようとすると拒否されること
4. ホスト側で比較が表示されること
